# Hilo — Backend

Bitácora de sesiones de **el motor (`core/`), los datos (`data/`), `scripts/` y `tests/`**. Sirve para retomar el trabajo sin tener que volver a explicar qué se estaba haciendo.

## Reglas

- **Un archivo por sesión**, con nombre `AAAA-MM-DD-tema.md` (ej. `2026-10-29-normalizacion.md`). Así quedan ordenados por fecha.
- Copiá `PLANTILLA.md` y completá: fecha, qué se hizo, qué faltó y el siguiente paso.
- Al **empezar** una sesión, leé el archivo más reciente y seguí desde "Siguiente paso".
- Al **terminar** una sesión, escribí su archivo antes de cerrar.
- No se borran sesiones viejas: son el historial.
